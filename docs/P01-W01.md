# P01-W01 — Cardboard Supply Data Model

## Scope

Introduces the submittable `Cardboard Supply` DocType inside
`cardboard_management`. Each document links one standard ERPNext Supplier, Item,
and Warehouse. Weights are recorded in Kg. The controller is authoritative for:

- `net_weight = gross_weight - tare_weight`
- `total_amount = net_weight * rate_per_kg`
- positive gross and net weight
- non-negative tare and rate
- tare lower than gross

The client script mirrors calculations for immediate form feedback only.
Submission intentionally has no accounting, buying, stock, payment, workflow,
or dashboard side effects.

## Test command

```bash
bench --site cardboard.localhost run-tests --app cardboard_management \
  --skip-before-tests --skip-test-records
```

The local development site has `allow_tests` enabled. Tests run in Frappe's test
transaction and roll back their temporary Supplier and Cardboard Supply records.
They cover calculations, server-side overwriting of derived values, save/submit,
zero boundaries, invalid weights/rate, complete schema metadata, one-item shape,
and absence of Purchase Invoice, Purchase Receipt, Stock Ledger Entry, and GL
Entry side effects.
