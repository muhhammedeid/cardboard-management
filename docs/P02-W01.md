# P02-W01 — Cardboard Management Workspace

## Scope

The Cardboard Management workspace is a public Desk workspace for daily operational
users. It surfaces the existing operational flow through standard Frappe/ERPNext
targets and adds no new doctypes, accounting, expense, dashboard, or hardware logic.
ERPNext and Frappe core were not modified.

## Where it lives

Standard metadata inside the custom app (synced by `migrate`, no fixture or hook
needed):

```
apps/cardboard_management/cardboard_management/cardboard_management/workspace/
├── content_builder.py                         deterministic renderer of the JSON
└── cardboard_management/cardboard_management.json
```

The JSON is the synced artifact; `content_builder.py` exists so the layout can be
regenerated instead of hand-editing deeply nested JSON. It runs outside Frappe
(`python3 content_builder.py`).

## Operational surface

- Shortcuts (Quick Actions): New Cardboard Supply, Cardboard Supplies, Suppliers,
  Payment Entries, Stock Balance (report), Items, Warehouses.
- Cards: Purchasing / Supplies (Cardboard Supply, Purchase Invoice); Suppliers &
  Payments (Supplier, Payment Entry); Inventory (Stock Balance report, Item,
  Warehouse); Reports (Stock Balance, Supplier Outstanding → standard Accounts
  Payable report, Purchase Register).
- "Coming Soon" note: Expenses, Dashboard, Scale Integration — Not implemented yet.

All labels are business-friendly; technical ERPNext complexity (Accounts module
workspace, Journal Entry, etc.) is not surfaced. The standard Accounts Payable
report is relabeled "Supplier Outstanding" inside this workspace only; the report
itself is untouched.

## What was not implemented

- No new or duplicate doctypes — existing Cardboard Supply remains the single
  operational ticket.
- No accounting/expense logic, no dashboards (charts/number_cards/quick_lists/
  custom_blocks all empty), no reports beyond links to standard reports, no scale
  hardware.
- No changes to ERPNext/Frappe.
